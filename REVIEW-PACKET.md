# Final judging package scope

Included: final video/PPT and real skill clip; all 16 historical main-run evidence files; new skill command/output journal and deployed artifacts; red 21→3 records; claimed small result files; four new skills and six internal components; retired report code for transparent review; public suite and strict training gate source; dataset manifests/head samples; ten-days article; per-file source and hash manifest.

Excluded: credentials, full model weights, sealed values, full raw training datasets, full vulnerable targets and an immediately executable payload library. Intentional exclusions mean this is not an offline end-to-end attack deployment.

Acceptance: reusable skill entry points and the registered real self-repair case, not arbitrary-target self-repair. Training drafts require independent label review, sample admission, sealed-family registry and quality checks. No next weights trained. Old runloop end-to-end and the report generator are not accepted capabilities. LLM fallback hit and brute_no_lock ladder remain future work.

Independent C reports are retained as supplementary repair-portability evidence with missing strict oracle checks and patch-provider boundaries stated. A JEV verdict never supersedes independent truth.

Current release, precise machine validation and model/source identity are authoritative; historical worklogs remain historical records, not a blanket completed checklist.
