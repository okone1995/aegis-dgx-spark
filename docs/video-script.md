# Aegis 四分钟演示脚本

这份脚本对应 2026-09-29 的最终剪辑。成片随比赛入口单独提交；仓库保留脚本、运行收据和技能调用证据，供评委沿运行编号核对。

## 故事主线

保险业务必须保护敏感数据，也必须保持正常服务。Aegis 把一次授权靶场中的风险发现，推进成可审查的修补：红方找证据，蓝方生成真实代码改动，独立门禁审查，原攻击重放，正常业务复测，结果再沉淀为可审核的经验和判官训练候选。这个受控循环是项目所说的 RSI；镜头用实际运行结果解释每一次“改进”。

页面发起任务，FastAPI 创建运行，DemoCase 负责阶段编排。外部 agent 可通过 Skills 调用同一能力；不要把四个 Skill 叙述成主演示轮次的后台自动编排器。Spark 上的补丁模型生成候选改动，JEV v3 只判交换流量的攻或正常，StepFun 复核候选 diff。
