# 十日谈 · Aegis 开发历程

> 这是一份按天记录的施工日志。每天先写当天栽的跟头，再写做了什么。踩的坑没有挑拣，都是当时真实发生的；每条失败都带 commit 或 run id，可以点开核对。D9、D10 写于提交日（2026-09-28）。

---

## D1 · 先把 125B 模型摸个底

**今日一败**：想用 `pkill -f download` 停一个下载脚本，结果模式串把自己的 shell 也匹配了进去，进程自杀，会话当场断线。这个坑后来又咬了我们三次（deploy.sh、抓包代理、批量脚本），最后定成两条规矩：杀服务先用 `ss -tlnp` 按端口找 PID；远端命令一律用单引号包住。按模式杀进程之前，先假设自己也在名单里。

**做了什么**：真机底座立起来了。Qwen3.8-Flash-Next 125B NVFP4 跑上 SGLang，三个实验定版：关思考模式后墙钟快 13 倍（17.4s→1.3s）；并发加满吞吐不变（约 23 tok/s 恒定）；StepFun 云端直连 0.57s。黑板状态机、scope 校验、payload policy 三件治理骨架当夜入库。commit：caaccd6、9584eaf、fcd2a83。

## D2 · 为什么要自己造一个有漏洞的网站

**今日一败**：验收 harness 首跑，12 发只中 7 发。upload 整组 payload 漏了 Cookie 头；sqli 的报错注入在 SQLite 上根本不成立，解析太宽容。原以为写好的武器库，一半是哑的。从这以后，held-out 验收成了硬门禁。

**做了什么**：edu-lite CMS 上线（A/B 双实例，参数名全不同），功能测试两边都 7/7；Step Code 四项 spike 全过，顺手发现 SGLang 不认 `developer` 角色，垫了个兼容层入仓；良性流量发生器产出 judge 标签源②。

## D3 · 第一次闭环：agent 自己补上了漏洞

**今日一败**：我宣布“re-attack 清零”，独立评审当场证伪。补丁重部署会清空 SQLite 会话，re-attack 复用的旧会话必然全部 401——这个收敛证明在数学上不可能失败，也就什么都没证明。修复：重放前强制重新认证，再加三把回归单测锁死。从这以后，“每个数字要能当场点验”成了项目的底线。

**做了什么**：A/B 双实例全闭环 CONVERGED（各 4.3s）。两个隐蔽坑入库：一是 opcache 时间窗，补丁后 2 秒内验证打到的还是旧代码缓存；二是回显假 marker，`VMARK9PASS` 被页面原样回显，漏洞“打不死”，后来重构判定面改用数据侧特征。commits：39a5a0e、73c3794。

## D4 · 漏洞类别即插件

**今日一败**：LLM 补丁适配首跑，产物被自家的 php -l 门禁拦下——`<?php` 头重复了，原因是我自己的 prompt 里多包了一层。好在失败路径（拒绝→accepted→恢复现场）走得很干净，这个反面例子本身就是当天的收获。

**做了什么**：upload_bypass、rce_deser 零管线改动接入，三个类别顺序闭环；LLM 适配层实弹 CONVERGED，57 秒，模板只要 2.8 秒——这 20 倍的时延差后来成了路由依据；StepRunner 从 spike 转生产。commit：85ed94f、9c2a1b0。

## D5 · 八类全通，以及“机器骗过自己”的两种方式

**今日一败**：两件。一是 xss 补丁生效后 verify 仍命中 3 条：`VULNXSS_A1()` 文本经 htmlspecialchars 转义后原样活着，marker 选错了判定面——该选“转义后必然消失的结构”，不是“看起来独特的文本”。二是 brute 攻击组打 admin，补丁生效前的 6 次失败把 admin 账号锁死，后面的会话全部连坐。前者改判定面，后者加了个牺牲性用户名。

**做了什么**：8/8 类全部闭环 CONVERGED（c01fe8b）；P0 三重审查门禁进管线，diff 边界、后门模式、异构复核，fail-closed，配 5 个单测；soak 1653 轮零失败起跑。

## D6 · 红蓝共演化，一个悬案告破

**今日一败**：lfi 类被“异构复核 API 瞬时故障”打回，fail-closed 把网络抖动当成了危险信号。这是设计行为，不是 bug，但它把一件事摆上了台面：fail-closed 的代价是可用性，阈值设计要诚实面对这一点。

**做了什么**：marathon 多轮收敛引擎（8 类 × 2 轮 10.3s，第 2 轮全类零命中）；Console 三栏工作台，参照 Rivet 重构；rce_deser 空写悬案告破，最小复现证明不是内容审查，是全文件长输出模式失败（fcd2a83）；judge 训练线跑通，家族级切分防孪生泄漏，评审抓出级 1 开卷 100% 不可信，证据留档当反面教材。

## D7 · 冻结日：数字只对测试负责

**今日一败**：评审发现“soak 1653 轮零失败”的日志里内存列是空的。零失败不等于测过内存，我们差点把一个没测过的维度当成通过项报出去。同一天，一份移交说明里的一条未核验声明也被评审抓住（P2-6）。从这以后，移交出去的说法同样必须能自证。

**做了什么**：B 集交卷并封存。judge 净卷 acc 0.9989（家族聚类 CI[0.9976,0.9998]，n=7266），对比零样本 0.8431；jail 两档 RoE 落地，重定向出笼的 P0 被评审抓住，用 `_pinned_request` 钉桩修复；级 3 口径主动降级，只主张改名鲁棒性与未见响应形态。

## D8 · 让第一次接触项目的人看得懂

**今日一败**：deck 初版的柱状图把 0.8431 四舍五入显示成了“1”，差一点在关键页挂出一个错数字。这个问题是逐页目检抓出来的，程序检查抓不到——工具能验证数值对不对，验证不了“看起来像什么”。

**做了什么**：把项目整理成不需要背景知识也能读的样子。JUDGES.md 提供三分钟导览路径和各项数字的出处映射；六页 deck 里每个数字都标了 JSON 来源；视频分镜定稿；另做了 golden-run 回放包，没有 Spark 环境也能完整重放整场对抗。

## D9 · 拍摄日（补记于提交日）

**今日一败**：下午第一次实拍，录到一半发现大屏上挂着前一天的数据，视频里“刚跑完的 run”时间戳是昨天的，全部重录。手册里多了一条规矩：开拍前先对时钟，页面取数的 `created_at` 和墙钟差超过 2 分钟就重置环境。另外，公网演示链接（Cloudflare 快速隧道）中途掉线重连了一次，地址会变——演示入口不能依赖随机域名，正式入口以提交包内的文件为准。

**做了什么**：4 分钟成片一次成型（`aegis-dgx-spark-demo-20260927.mp4`，SHA256 `45514fad…`，分镜见 `docs/video-script.md`）。主线是 `run-20260927-140612-399b`：修补前 SQLi marker 命中，三道门禁 3 项 PASS，修补后同一注入重放 0/2，正常业务断言通过（「图书馆」命中、无效关键字不命中），靶场恢复（restored），run succeeded。一次运行留下攻击复测、门禁、部署身份（runtime-attestation 记录补丁模型 `Qwen3.8-Flash-Next-NVFP4-SSD-Stream`）和收据全链。RSI 9 页 deck 同日定稿（`aegis-dgx-spark-judge-pitch-rsi-20260928.pptx`，SHA256 `a4eb9107…`），把“受控 RSI”讲成四步：红方自挖风险、JEV 独立判流量、蓝方受门禁约束的自修补、结果回流为判官训练材料。deck 里也如实写了边界：参赛的是已训练、已部署的 v3；本轮新样本要人审通过才进下一轮训练，下一版判官还没开训。这不是藏着的秘密，是主张的边界。

## D10 · 提交与复盘（补记于提交日）

**今日一败**：提交包第一版差点带病出门。独立复核（2026-09-28）连抓三处：一，打包规则会漏掉手工补入的证据和结果 JSON，“构建两次结果一致”从此成为硬要求；二，训练材料链的标签把“攻击但没打穿”错标成了“良性”，早先“107/122 判官误报”的结论随之作废——是我们的标签口径错了，不能再拿它去断言判官读数的对错，116 条旧候选已重标隔离，旧标签在 `legacy_labels` 留痕；三，README 承诺了包里不存在的运行路径，缺靶站和载荷却写“可跑完整攻击链”。修正过程中又陆续暴露了数据保真、标签审批、媒体验收几处漏洞，一并补齐，写成规则：导出白名单、构建后断言、`training_ready` 闸门（训练入口非零退出）、评审包三条准确入口（看、自包含测试、授权 LIVE）。

**做了什么**：本地最终包重新构建，交付四分钟更新视频、9 页 RSI deck、44.233 秒真实技能短片、主 run 16 件证据、数字结果和逐文件哈希。此前“媒体表只是定义了、没实际验过哈希”的假通过已纠正。能力线公开验收 75 passed / 16 subtests passed；最终包与干净解压验证记录在 VALIDATION.json，没有冒称私有/GPU 套件全部通过。

**补录**：run-20260928-155647-3290 由技能 CLI 启动，约 90 秒到终态，返回 verified_restored、17/17 证据核验、5 条候选入队。完整操作留了底，短片只把等待段压成 4× 并加了中文合成旁白，替换了原来的静态技能片段。下一版判官仍未开训。源码双来源、脱敏副本与原文件的字节差异都写进了清单；正式上传由负责人手动完成，没拿到的凭证不写成已有。

**复盘三条**（如果只记住三件事）：

1. **判定只认硬信号**。marker、业务门禁、复测说了算，模型读数只用来分析分歧。“像攻击”不等于“是攻击”，“没打穿”也不等于“是良性”。把意图和结果分开，是这个版本里最贵的一课。
2. **失败必须留痕、可复核**。每条败笔都带 commit 或 run id。判官与我们的分歧、构建断言、泄漏扫描，这些制度都是为了让“我们错了”这件事能被机器抓住，而不是靠自觉。
3. **对外每个数字带口径和快照时间**。v1/v3 的时延不互相引用，两档悬置带不混用，台账写明每轮测于何时。可信不来自完美，来自可核验。
