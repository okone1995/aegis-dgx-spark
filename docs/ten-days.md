# 十日谈 · Aegis 开发历程

> 体例：保持施工日志体；每天以《今日一败》开篇——失败先于成绩，因为我们的方法论就是从失败里长出来的。每条败笔带 commit/记录锚点，可查证。本文为 D9 交付的重构底稿（每日素材实拍于施工当天，非事后编造；D9/D10 已于提交日补完（2026-09-28））。

---

## D1 · 我们把 125B 模型测了个底朝天

**今日一败**：我用 `pkill -f download` 想停一个下载脚本，模式串匹配到了自己所在的 shell——进程自杀，会话当场断线。这个坑后来又咬了我们三次（deploy.sh、抓包代理、批量脚本），最终制度化为两条铁律：杀服务用 `ss -tlnp` 按端口取 PID；远端命令单引号包裹。教训：模式匹配杀人时，先假设自己也是匹配对象。

**事**：真机底座立起来——Qwen3.8-Flash-Next 125B NVFP4 上 SGLang；三个实验定版：关思考模式 13 倍墙钟加速（17.4s→1.3s）、并发不涨吞吐（~23 tok/s 恒定）、StepFun 云端直连 0.57s。骨架与治理三件（黑板状态机/scope 校验/payload policy）当夜入库。commit：caaccd6、9584eaf、fcd2a83。

## D2 · 为什么要自己造一个有漏洞的网站

**今日一败**：验收 harness 首跑 12 发只中 7 发——upload 全组 payload 漏了 Cookie 头，sqli 的错误注入姿势在 SQLite 上根本无效（宽容解析）。原以为"写好了"的武器库，一半是哑的。held-out 验收从此成为硬门禁。

**事**：edu-lite CMS（A/B 双实例、参数名全异）上线，功能测试双 7/7；Step Code 四项 spike 全过（发现 SGLang 不认 `developer` 角色，垫片入仓）；良性流量发生器产出 judge 标签源②。

## D3 · 第一次闭环：agent 自己补上了漏洞

**今日一败（本日最重）**：我宣布"re-attack 清零"，独立评审当场证伪——补丁重部署清空了 SQLite 会话，re-attack 复用的旧会话必然全部 401，**收敛证明在数学上不可能失败，也就什么都没证明**。修复：重放前强制重新认证 + 三把回归单测锁死。此后"每个数字可当场点验"成为项目宪法。

**事**：A/B 双实例全闭环 CONVERGED（各 4.3s）；两个隐蔽坑入库——opcache 时间窗（补丁后 2 秒内验证打的是旧代码缓存）和回显假 marker（`VMARK9PASS` 被页面原样回显，漏洞"打不死"——修复方式是重构判定面用数据侧特征）。commits：39a5a0e、73c3794。

## D4 · 漏洞类别即插件

**今日一败**：LLM 补丁适配首跑，产物被自家 php -l 门禁拦下——重复的 `<?php` 头，是我 prompt 里多包了一层。失败路径（拒绝→accepted→恢复现场）全程干净，反而是当天最好的素材。

**事**：upload_bypass / rce_deser 零管线改动接入，三类别顺序闭环；LLM 适配层实弹 CONVERGED（57s vs 模板 2.8s，20 倍时延差成为路由依据）；StepRunner 从 spike 变生产。commit：85ed94f、9c2a1b0。

## D5 · 八类全通，以及"机器骗过自己"的两种方式

**今日一败（×2）**：①xss 补丁生效后 verify 仍 3 条命中——`VULNXSS_A1()` 文本经 htmlspecialchars 转义后**原样存活**，marker 选错了判定面（要选"被转义必然消灭的结构"，不是"看起来独特的文本"）；②brute 攻击组打 admin，补丁生效前 6 次失败把 admin 锁死——后续全部会话陪葬。前者改判定面，后者改"牺牲性用户名"。

**事**：8/8 类全部闭环 CONVERGED（c01fe8b）；P0 三重审查门禁入管线（diff 边界/后门模式/异构复核，fail-closed 带 5 单测）；soak 1653 轮零失败起跑。

## D6 · 红蓝共演化与一个悬案的破案

**今日一败**：lfi 类被"异构复核 API 瞬时故障"打回——fail-closed 把网络抖动当成了危险信号。这是设计行为而非 bug，但它提醒我们：fail-closed 的代价是可用性，阈值设计要诚实面对这一点。

**事**：marathon 多轮收敛引擎（8 类 × 2 轮 10.3s，R2 全类零命中）；Console 三栏工作台（评审参照 Rivet 级重构）；rce_deser 空写悬案破案——最小复现证明非内容审查，是全文件长输出模式失败（fcd2a83）；judge 训练线跑通（家族级切分防孪生泄漏，评审抓出级 1 开卷 100% 不可信，证据归档为反面教材）。

## D7 · 冻结日：所有数字只对考卷负责

**今日一败**：评审发现"soak 1653 轮零失败"的日志里**内存列全空**——零失败 ≠ 测过内存。我们差点把一个没测过的维度当成通过项宣传。同日，另一会话的移交叙述里一条未经核验的声明被评审当场抓获（P2-6），从此"移交声明同样必须可自证"入宪。

**事**：B 集交卷并永封——judge 净卷 acc 0.9989（家族聚类 CI[0.9976,0.9998]，n=7266）vs 零样本 0.8431；jail 两档 RoE 落地，重定向出笼 P0 被评审抓获并由 `_pinned_request` 钉桩修复；级 3 口径主动降级（只主张改名鲁棒性与未见响应形态）。

## D8 · 把工程翻译成评委的语言

**今日一败**：deck 初版柱状图把 0.8431 四舍五入显示成"1"——差一点在深度证据页挂出一个错误数字。视觉 QA（逐页目验）抓的，不是编译器抓的。程序化检查测不出"看起来像什么"。

**事**：评委触达层成体系落地——JUDGES.md（三分钟评审路径 + 百分映射）、六页 deck（每数字带 JSON 出处）、视频分镜定稿、golden-run 回放包（无 Spark 的评委可完整重放战役）。

**复盘三条**（如果只记住三件事）：
1. **判定只认硬信号**——marker/业务门禁/复测说了算；模型读数只作分歧分析。"像攻击"不等于"是攻击"，"没打穿"也不等于"是良性"——把意图与结果分开，是我们这个版本最贵的一课；
2. **失败必须留痕并可复核**——每条败笔带 commit 或 run id；判官与我们的分歧、构建断言、泄漏扫描，都是让"我们错了"这件事**能被机器抓住**的制度；
3. **对外每个数字带口径与快照时间**——v1/v3 时延不互引、两档悬置带不混用、台账轮次写明测于何时。可信不来自完美，来自**可核验**。
